# amaha-staff-roster

Staff roster for the VRChat world "天羽 (AMAHA)". The world downloads `staff.txt` once when it starts and lets the
listed display names through the staff-only areas and use staff-only gimmicks.

## スタッフの増やし方・減らし方
1. GitHub でこのリポジトリの `staff.txt` を開き、鉛筆マーク（Edit）を押す。
2. VRChat の表示名を1行に1人ずつ書く（大文字・小文字・記号も表示どおり）。`#` で始まる行と空行は無視される。
3. 「Commit changes」で保存する。
4. 反映は新しく開いたインスタンス（または入り直し）から。GitHub Pages の更新とキャッシュで数分〜10分ほど遅れることがある。

ワールドが読む URL: `https://chikarappo.github.io/amaha-staff-roster/staff.txt`

注意: このリポジトリは公開（VRChat から読むため）。表示名以外は書かないこと。
